# lowpoplabs.github.io

The LowPopLabs plugin catalogue, served by GitHub Pages and embedded by URL into
the Google Sites pages at https://sites.google.com/view/lowpoplabs.

Everything here is **generated**. Don't edit it in place: the sources are the
manifest and the Google Sites kit in the private ProjectHosting folder, and
`release.py sites` rebuilds and pushes this repo.

| Path | What it is |
|---|---|
| `index.html` | The catalogue as a standalone page |
| `embed/header.html`, `embed/cards.html`, `embed/footer.html` | The three blocks the Sites home page embeds |
| `flyers/<Plugin>.html` | One flyer page per plugin, embedded by its Sites page |
| `assets/` | Logo and banner |

Plugins are free and MIT-licensed. Source and releases: https://github.com/lowpoplabs
