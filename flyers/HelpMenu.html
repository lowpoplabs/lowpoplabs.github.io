Island Taxi

Dial 555-TAXI1 from any phone: pick a vehicle, drop a map pin, ride. Fares in scrap, paid up front.

COMMANDS
/taxi cancelCancel your booking or current ride
HOW TO
1.  Use any phone and dial 55582941 — it's in the directory.
2.  Pick a vehicle, pin your destination, confirm the fare.
3.  Wait — your ride arrives from off the map.

One Command

/help opens the guide. Pick a topic on the left, read on the right, scroll when it runs long. Close it and get back to dying of cold.

Ask In Chat

In a hurry? /help taxi prints that page straight into chat — name or first few letters, either works.

Talk Back

The Feedback button takes a note and puts it in the owner's box. Broken, confusing, missing — say so. It gets read.

Always Current

The menu lists what's actually running on the server right now — nothing more. If a page is in there, the feature works today. No stale wiki, no guessing which commands still exist, no flyer archaeology. (This flyer excepted. Keep this flyer.)
